Computer Networks Seminar — upgraded static website

Files:
- index.html: seminar pages, presenter details and feedback form
- style.css: responsive design and animated diagram styling
- script.js: navigation, interactive lessons and packet animation

Run locally: keep all three files in the same folder and open index.html.
Deploy: upload all three files to the root of a GitHub Pages repository.

Animation key:
- Red dashed paths = network connections
- Green moving dots = sender direction
- Blue moving dots = receiver direction (opposite direction on the same path)

Feedback opens Gmail web compose addressed to adb78161@gmail.com. The visitor must press Send; the static website cannot send email by itself.
Device illustrations are inline SVG and do not require Python packages.
