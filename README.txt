COMPUTER NETWORKS 3D SPHERE WEBSITE
Files: index.html, style.css, script.js
This recreates a 3D sphere gallery using CSS 3D transforms and plain JavaScript. It does not require React or Motion+.

Run in Acode:
1. Extract the ZIP.
2. Open the folder in Acode.
3. Preview index.html in a browser.
4. Internet is needed for Bootstrap CDN and Google Fonts.

GitHub Pages:
Upload the three website files to the root of a GitHub repository.
Open Settings > Pages > Deploy from a branch > main > /(root) > Save.

Edit presenter name/class in index.html. Edit network lesson text and diagrams in the data object in script.js.
The green and blue dots are animated data packets; red lines show connections.
