COMPUTER NETWORKS SEMINAR — BOOTSTRAP EDITION
================================================

Files:
- index.html
- style.css
- script.js

Tech:
- HTML5, CSS3 and vanilla JavaScript
- Bootstrap 5.3.3 via official jsDelivr CDN
- No Python, npm, build process or backend required

Run locally:
1. Keep all three files in the same folder.
2. Open index.html in a browser. Internet is needed for Bootstrap CDN assets and any remote form endpoint.

Deploy to GitHub Pages:
1. Upload index.html, style.css and script.js to the repository root.
2. Commit changes.
3. In Settings > Pages, select Deploy from a branch, branch main, folder /(root).

Notes:
- Bootstrap is loaded from CDN, so an internet connection is needed for Bootstrap's CSS/JS.
- Custom styles preserve the seminar's light, soft-card design.
- Data-flow dots and lines are educational simulations, not live network monitoring.
- For direct email delivery from a static site, a form service or backend is required; Gmail itself does not permit anonymous sending from browser-only code.
