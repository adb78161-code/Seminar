COMPUTER NETWORKS — HELIX SEMINAR WEBSITE
==========================================

Files:
- index.html
- style.css
- script.js

HOW TO USE IN ACODE
1. Extract the ZIP.
2. Open the Computer_Networks_Helix_Seminar folder in Acode.
3. Open index.html and preview it in a browser.
4. Enter presenter details on the cover page.
5. Explore PAN, LAN, MAN and WAN by selecting the rotating cards.
6. Use the final Feedback page to compose an email.

GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. Go to Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.

FEEDBACK EMAIL NOTE
The feedback button uses a mailto link addressed to aditya586120@gmail.com.
It opens the visitor's configured email application with the feedback prefilled.
The visitor must press Send. A static GitHub Pages website cannot silently send
email by itself; that requires a backend or a third-party form service.

NOTES
- Presenter details are kept in the browser's local storage on that device.
- Bootstrap and Google Fonts load from their CDNs, so an internet connection
  is needed for those external resources.
- The diagrams are illustrative animated schematics, not to-scale engineering
  topology drawings.
