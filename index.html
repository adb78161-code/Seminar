01 / THE BASICS

Everything starts
with a connection.

A computer network is a group of devices connected to exchange data and share resources using wired or wireless links.

Example

Your phone sends a photo to a laptop over Wi-Fi, or a computer sends a document to a shared printer.

Connection flow

Device → communication link → network equipment → destination device.

Four network types
NETWORK TYPE 01
PERSONAL · SHORT RANGE

PAN Network

A Personal Area Network connects personal devices over a short distance, commonly using Bluetooth.

Real-life example

A phone connects wirelessly to Bluetooth earbuds and a smartwatch. Audio travels from the phone to the earbuds.

How the connection works

  1. Enable Bluetooth on the phone.
  2. Pair the earbuds with the phone.
  3. The phone sends audio data wirelessly.

NETWORK TYPE 02
ROOM · BUILDING · CAMPUS

LAN Network

A Local Area Network connects computers and shared equipment within a limited area.

Real-life example

A college computer lab connects desktop PCs to a network switch. The switch connects to a router for internet access.

How the connection works

  1. PC sends data through an Ethernet cable.
  2. The switch forwards data to the intended device.
  3. The router provides a route to other networks.

NETWORK TYPE 03
TOWN · CITY

MAN Network

A Metropolitan Area Network connects multiple local networks across a town or city.

Real-life example

Different college campuses in the same city connect using provider-managed fibre links.

How the connection works

  1. Each campus has its own LAN.
  2. Routers connect the campus LANs to a metropolitan link.
  3. Data travels across the city network to another site.

NETWORK TYPE 04
REGIONAL · GLOBAL

WAN Network

A Wide Area Network connects networks over large distances, across regions, countries or continents.

Real-life example

A user in India accesses a website hosted on a server in another country through multiple networks and routers.

How the connection works

  1. Your device sends data to the local router.
  2. Routers forward packets through provider networks.
  3. The destination server replies across the network.
